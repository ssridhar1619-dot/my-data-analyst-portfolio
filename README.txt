Sridhar Senthil Kumar — Portfolio Website
==========================================
GitHub Pages deployment:
1. Upload index.html to the root of your GitHub repository.
2. Open repository Settings > Pages.
3. Under Build and deployment, choose Deploy from a branch.
4. Select main branch and /(root), then Save.
5. Wait for the Pages URL to appear in Settings > Pages.

This is a static website and does not require a build step.
